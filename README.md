## Selected Work

> **[friday](https://github.com/devkkxingh/friday)** &nbsp;&middot;&nbsp; `Latest`<br>
> A personal automation agent for macOS, controlled entirely through WhatsApp — runs shell and native macOS automation, drives a real Chrome profile, and handles two-way voice notes. Built on the Claude Agent SDK.<br>
> <sub>`TypeScript` &nbsp; `Claude Agent SDK` &nbsp; `macOS` &nbsp; `Automation`</sub>

> **[krenk](https://github.com/devkkxingh/krenk)** &nbsp;&middot;&nbsp; [npm ↗](https://www.npmjs.com/package/krenk)<br>
> A multi-agent software-engineering CLI that orchestrates a team of specialized AI agents — from planning to deployment — assigning the right job to the right agent, like a real engineering team.<br>
> <sub>`TypeScript` &nbsp; `Multi-Agent` &nbsp; `Claude` &nbsp; `CLI`</sub>

> **[SnapYour.Codes](https://github.com/devkkxingh/snapyour.codes)** &nbsp;&middot;&nbsp; [Live ↗](https://snapyour-codes.vercel.app)<br>
> A polished code-snippet screenshot generator for capturing, customizing, and exporting beautiful code images with configurable themes and a responsive UI.<br>
> <sub>`React` &nbsp; `Redux` &nbsp; `Tailwind CSS` &nbsp; `Radix UI`</sub>

> **[Lavio-AI](https://github.com/devkkxingh/Lavio-AI)**<br>
> Real-time voice conversations with AI for enhanced web browsing and productivity, powered by Chrome's built-in AI.<br>
> <sub>`JavaScript` &nbsp; `Chrome Extension` &nbsp; `Built-in AI` &nbsp; `Voice`</sub>

> **[Shopify Next.js Integration](https://github.com/devkkxingh/shopify-nextjs-external)**<br>
> A secure, enterprise-grade Next.js app for Shopify store integration — OAuth authentication, JWT session management, and encrypted token storage.<br>
> <sub>`Next.js 15` &nbsp; `TypeScript` &nbsp; `Shopify API` &nbsp; `OAuth`</sub>

> **[fetch-reactive](https://github.com/devkkxingh/fetch-reactive)**<br>
> A zero-dependency reactive fetch wrapper for JavaScript and TypeScript.<br>
> <sub>`TypeScript` &nbsp; `Library` &nbsp; `Zero-Dependency`</sub>
