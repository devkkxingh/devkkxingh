## Selected Work

### Shopify Next.js External App

A secure Next.js application that integrates with Shopify stores via OAuth — a foundation for building Shopify apps with JWT session management, encrypted token storage on Supabase, and middleware-protected routes.

<sub>**Stack** · Next.js 15 · TypeScript · Tailwind CSS · Shopify API · OAuth · JWT · Supabase</sub>

### SnapYour.Codes

An intuitive code-snippet screenshot generator for capturing, customizing, and exporting polished code images, with configurable themes and a fully responsive interface.

<sub>**Stack** · React · Redux · Tailwind CSS · Headless UI · Radix UI</sub>

### LeetCode Guru — Chrome Extension

A Chrome extension that simplifies LeetCode problems with clear explanations, interactive hints, and worked examples, surfaced directly in the browser side panel.

<sub>**Stack** · Chrome Extension · Side Panel API</sub>

### Book Reading Assistant &nbsp;<sub>In Development</sub>

<sub>**Stack** · OCR · Text-to-Speech · Translation</sub>

<sub>**Stack** · Three.js · Cannon.js</sub>
