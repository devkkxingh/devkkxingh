## 🚀 Highlighted Projects



### 🛒 Shopify Next.js External App
A secure, modern Next.js application integrating with Shopify stores via OAuth. Provides a foundation for building Shopify apps with secure session management (JWT), encrypted token storage (Supabase), and middleware-protected routes.
*   **Tech:** Next.js 15, TypeScript, Tailwind CSS, Shopify API, OAuth, JWT, Supabase.
*   **Features:** Secure OAuth, Session Management, Encrypted Token Storage, Middleware Protection.

### ✨ SnapYour.Codes
An intuitive code snippet screenshot generator. Capture, customize, and generate stylish code images effortlessly.
*   **Tech:** React, Redux, Tailwind CSS, Headless UI, Radix UI.
*   **Features:** Code Screenshot Generation, Customizable Themes, Responsive UI.

### 🎮 Stack 'Em High
A physics-based block stacking game demonstrating 3D graphics and physics simulation.
*   **Tech:** Three.js, Cannon.js (Physics Engine).
*   **Features:** Dynamic Physics, Wind Effects, 3D Rendering.

### 🧠 LeetCode Guru (Chrome Extension)
A Chrome extension simplifying LeetCode problems with clear explanations, interactive hints, and example breakdowns directly in the browser side panel.
*   **Features:** Simple Explanations, Interactive Hints, Example Breakdowns, Side Panel Integration, One-Click Access.

### 🌐 WebDev Club Community
[webdev-club.vercel.app](https://webdev-club.vercel.app) - A vibrant community platform for frontend developers.
*   **Focus:** Learning, Sharing, Collaboration (JavaScript, React, Angular, CSS, etc.).

### 📚 Book Reading Assistant App (In Development)
An accessibility-focused app using OCR and Text-to-Speech to assist users with reading difficulties by scanning and vocalizing book content.
*   **Focus:** Accessibility, OCR, Text-to-Speech, Translation.
